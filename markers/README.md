# Markers

- `landing_marker_A3.pdf`: ArUco 4x4_50, id 0. Print on A3 at 100% (no "fit to page"). Measure the black square and pass it as `--marker-size` in metres (about 0.26 on A3).
- `landing_marker.png`: the same marker for A4 (about 0.20 m).
- `checkerboard.png`: camera calibration board, print on A4 landscape at 100% (25 mm squares).

Lay the marker flat and weigh the corners down so the downdraft can't lift it.
